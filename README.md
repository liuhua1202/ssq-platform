## 🚀 快速开始

### 方式一：使用发布版本（无需安装 Python）

1. 复制 `发布版本` 文件夹到任意位置
2. 双击运行 `启动.bat`
3. 浏览器自动打开 http://localhost:5000

### 方式二：源代码运行（需要 Python）

```bash
# 安装依赖
pip install -r requirements.txt

# 启动应用
python app.py
```

### 访问平台

打开浏览器访问：**http://localhost:5000**

### 首次使用（重要！）

首次使用请清除浏览器缓存：
1. 按 `Ctrl + Shift + Delete`
2. 选择"缓存的图像和文件"
3. 点击"清除数据"
4. 或强制刷新：`Ctrl + F5`

## 📖 使用指南

### 号码预测

1. 点击"号码预测"标签
2. 选择算法（推荐"综合推荐"）
3. 设置生成注数（默认 5 注）
4. 点击"生成预测号码"
5. 点击"收藏"保存心仪号码

### 历史数据

- 查看历史开奖记录（300 条）
- 支持分页浏览（每页 50 条）
- 点击"数据管理"可导入/备份/恢复

### 数据分析

查看统计信息：
- 🔥 **热号**：出现频率最高的号码
- ❄️ **冷号**：出现频率最低的号码
- 📊 **遗漏统计**：当前遗漏值最大的号码
- 🔵 **蓝球分析**：蓝球的热号和冷号

### 号码分析

1. 输入 6 个红球（1-33）和 1 个蓝球（1-16）
2. 点击"分析号码"
3. 查看与历史数据的匹配情况和历史匹配记录

### 我的号码

- 查看收藏的号码
- 显示算法和备注信息
- 可删除不需要的号码

### 数据管理

- **备份**: 创建当前数据的备份
- **恢复**: 从备份文件恢复数据
- **导入**: 支持 JSON/CSV/TXT 格式
- **清空**: 清空所有历史数据（谨慎使用）

### 导出功能

- **导出收藏号码**: JSON 格式
- **导出历史数据**: JSON 格式

## 🔧 故障排除

### 问题：无法正常生成预测数据

**快速诊断**：
```bash
# 运行诊断工具
docs/diagnose.bat

# 或测试后端
python -c "from app import app; print('OK')"
```

**解决方案**：

1. **清除浏览器缓存**（最常见）
   - Windows: `Ctrl + Shift + Delete`
   - 选择"缓存的图像和文件"
   - 点击"清除数据"

2. **检查浏览器控制台**
   - 按 `F12` 打开开发者工具
   - 查看 Console 标签的错误信息
   - 查看 Network 标签中 API 请求状态

3. **重启 Flask 应用**
   - 停止当前运行中的应用（Ctrl+C）
   - 重新启动：`python app.py`

### 问题：提示"暂无历史数据"

**解决方案**：
1. 检查 `data/history.json` 文件是否存在
2. 如果文件为空或不存在，需要导入历史数据
3. 访问"历史数据" -> "数据管理" -> 导入数据

### 问题：API 请求失败

**检查步骤**：
1. 确认 Flask 应用已启动
2. 检查 Network 标签中请求状态码
   - `200`: 正常
   - `404`: 后端未启动或路由错误
   - `500`: 服务器内部错误
3. 查看 Flask 日志输出

### 回退方案

如果新版本有问题，可以查看 `docs/` 目录中的详细文档获取帮助。
