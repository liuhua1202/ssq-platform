📚 数据管理指南

💡 重要提示

本平台仅支持手动导入历史数据，请从官方网站或其他数据源获取数据后手动导入。

📥 手动导入历史数据

支持 JSON、CSV、TXT 格式，也可直接粘贴网页表格数据

支持的数据格式

JSON 格式（推荐）: 
[
  {
    "issue": "2024001",
    "red_balls": [5, 10, 15, 20, 25, 30],
    "blue_ball": 8,
    "date": "2024-01-02"
  },
  {
    "issue": "2024002",
    "red_balls": [3, 8, 17, 22, 28, 31],
    "blue_ball": 12,
    "date": "2024-01-04"
  }
]
CSV 格式: 
issue,date,red_balls,blue_ball
2024001,2024-01-02,"5,10,15,20,25,30",8
2024002,2024-01-04,"3,8,17,22,28,31",12
TXT 格式: 
2024001,2024-01-02,5,10,15,20,25,30,8
2024002,2024-01-04,3,8,17,22,28,31,12

格式：期号,开奖日期,红球 1,红球 2,红球 3,红球 4,红球 5,红球 6,蓝球

📥 获取历史数据的渠道

  • 中国福彩网官网 - https://www.cwl.gov.cn/ygkj/wqkjgg/ssq/
  • 500 彩票网 - https://kaijiang.500.com/ssq.shtml
  • 其他公开数据源 - 选择可信的彩票数据网站

⚠️ 数据导入注意事项

  • 红球必须是 6 个 1-33 之间的不重复数字
  • 蓝球必须是 1 个 1-16 之间的数字
  • 期号格式建议为 YYYYXXX（如 2024001）
  • 日期格式为 YYYY-MM-DD（如 2024-01-02）
  • 系统会自动去重，相同期号保留最新导入的数据
